# Desugaring joins the e2e contract

The core language now has its own smoke path.

Until now, `--desugar` was checked manually by running the normal manifest with
a different parser command. That was useful, but it was not part of the
repository's declared test shape. This slice adds `e2e/desugar-manifest.txt` and
wires it into the flake check.

The desugar manifest is intentionally focused. It covers:

- static dotted bindings lowering into nested core attrsets
- dynamic attribute names lowering into dynamic core assignments
- scoped inherit lowering into core selections
- selection defaults and string interpolation
- one surface validation failure that must stop before core output

This gives the core pipeline its own regression surface without duplicating the
entire parser corpus. The regular manifest still answers "does this parse and
validate as Nix surface syntax?" The desugar manifest answers "does the accepted
surface tree lower into checked core?"
