# Float values enter evaluation

Float literals now evaluate to an explicit core value:

```text
NixParserLean.Core.Eval.Value.float "1.0"
```

The evaluator deliberately keeps arithmetic narrow for now. Integer arithmetic
is still supported, but float-only arithmetic and mixed int/float arithmetic
both fail with the existing unsupported-operand diagnostic. That gives us a
stable value form without smuggling in an accidental numeric tower.

String interpolation also remains conservative: floats are values now, but they
are not string-compatible values. The existing interpolation failure fixture now
checks that boundary directly.
