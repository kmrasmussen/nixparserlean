# NixParserLean Tickets

This backlog captures durable project direction. It is intentionally small.

Use tickets for semantic milestones, proof targets, corpus infrastructure, and
design debt that should survive across individual coding sessions. Do not add a
ticket for every fixture, typo, or narrow commit.

Each significant implementation slice should still be small, tested, blogged,
and committed independently. Tickets are the map; commits are the trail.
